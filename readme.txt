Construtor visual completo em um único plugin, com atualizações automáticas.

== Description ==

O Forma Elements junta o Elementor e o PRO Elements em um único plugin e recebe atualizações automaticamente,
sempre testadas antes de chegar ao seu site.

Compatível com os addons de Elementor (ElementsKit, Royal Addons, Essential Addons, Happy Addons e outros).

Créditos: Elementor (https://wordpress.org/plugins/elementor/) e PRO Elements (https://proelements.org/),
ambos distribuídos sob a licença GPL, sem alterações no código.

== Installation ==

1. Desative o Elementor, o Elementor Pro ou o PRO Elements, se estiverem ativos. As páginas não são perdidas.
2. Envie o forma-elements.zip em Plugins > Adicionar novo > Enviar plugin.
3. Ative o Forma Elements.
